# 4.08 La variable fromAI

## Resume
- Introduction au module sur la variable FromAI de N8n via sa documentation officielle : dès qu'un outil est connecté à un agent, deux modes d'usage sont possibles (contrôle total de l'agent ou définition manuelle).
- Explication technique de la syntaxe FromAI : fonctionne comme une fonction où l'on définit la valeur à récupérer dynamiquement selon le contexte de la requête de l'agent.
- Présentation des paramètres de FromAI : définition du type de valeur (ex : String) et d'une valeur par défaut (ex : date au format 2025-07-14) pour cadrer la réponse attendue de l'IA.
- Exemple concret de configuration FromAI pour un attribut nommé (nom du commentateur) avec description, type String et valeur d'exemple par défaut, avec option de simplification si besoin.

## Concepts cles
- introduction à la variable FromAI et ses deux modes d'usage (automatique vs manuel)
- explication technique de la syntaxe fonctionnelle FromAI
- paramètres de FromAI : type de valeur et valeur par défaut
- exemple concret de configuration FromAI pour un attribut nommé avec description

## Outils mentionnes

## Tips techniques
- Toujours définir un type et une valeur par défaut pour chaque paramètre FromAI, pour cadrer précisément la réponse attendue de l'agent
