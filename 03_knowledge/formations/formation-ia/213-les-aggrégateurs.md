# 2.13 Les aggrégateurs

## Resume
- Introduction aux agrégateurs, expliqués par un schéma comparatif avec les itérateurs : là où l'itérateur sépare un Array pour répéter une action sur chaque élément, l'agrégateur fait l'opération inverse.
- Démonstration de l'agrégation de valeurs multiples : le module récupère toutes les lignes individuelles (1200, 6000, 40000, 8000) pour les combiner en un résultat total unique, illustrant le rôle central de l'agrégateur.
- Présentation de la fonction Map appliquée à un agrégateur : sélectionner l'Array entier puis définir la valeur souhaitée (exemple : prénom, email) pour extraire spécifiquement cette donnée de chaque élément agrégé.
- Synthèse sur l'utilité des agrégateurs d'array : transformer des listes de bundles récupérées en un array propre et exploitable, réutilisable ensuite via des envois groupés ou d'autres traitements en aval.

## Concepts cles
- agrégateurs comme opération inverse des itérateurs
- exemple concret d'agrégation de valeurs multiples en un résultat unique
- fonction Map pour extraire une valeur spécifique d'un Array agrégé
- synthèse : agrégateurs pour créer un array propre et exploitable
