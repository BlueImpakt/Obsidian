# 0.32 ChatGPT sur Mac ou Windows

## Resume
- Introduction à la comparaison entre ChatGPT version web et version desktop (application native pour ordinateur). L'auteur montre la procédure d'installation : se rendre sur le site ChatGPT, cliquer sur le bouton de téléchargement, puis choisir la version macOS ou Windows selon son système.
- Après installation, l'auteur note un souci de détection du micro à corriger plus tard. Présentation du mode application, propre à la version desktop, qui permet de connecter ChatGPT directement à des applications préprogrammées comme Notion, VS Code et Cursor.
- Démonstration du mode application en action avec un plan marketing détaillé généré par ChatGPT (partenariats différenciants, offres psychologiques, email marketing narratif). L'auteur souligne que ce mode permet de copier et d'ajouter facilement le contenu généré directement dans l'application connectée, avec modification en temps réel.
- Tour des paramètres disponibles sur la version desktop : upgrade vers ChatGPT Pro, personnalisation, notifications, connecteurs, contrôle des données, chats archivés, sécurité. Présentation du réglage permettant de choisir si les liens ChatGPT s'ouvrent dans le navigateur web ou directement dans l'application desktop.
- Démonstration de l'activation/désactivation d'une fonctionnalité (visible immédiatement dans l'interface une fois le réglage changé). Présentation de l'application automatique des modifications suggérées (edits appliqués automatiquement) et des suggestions d'autocomplétion préconfigurées pour la dictée vocale.
- Clôture de la comparaison web/desktop : accès aux GPT personnalisés (exemple : GPT Monday) directement depuis l'application desktop. L'auteur conclut que les différences entre les deux versions ne sont pas énormes, mais souhaitait montrer les deux fonctionnalités natives les plus notables, en particulier tester si le micro est bien détecté.

- installation de l'application desktop ChatGPT

- panorama des paramètres desktop
- choix d'ouverture des liens (web vs application)
- application automatique des edits suggérés
- autocomplétion pour la dictée vocale
- accès aux GPT personnalisés en desktop
- synthèse des différences web vs desktop (limitées)
