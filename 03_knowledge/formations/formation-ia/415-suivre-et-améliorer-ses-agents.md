# 4.15 Suivre et améliorer ses agents

## Resume
- Introduction au suivi de la qualité de réflexion d'un agent : ajouter à la dernière étape du flow un enregistrement dans Google Sheets pour tracer la performance dans le temps.
- Présentation de l'option Return Intermediate Steps permettant de récupérer le détail complet des étapes de réflexion suivies par l'agent pour arriver à son résultat.
- Détail du contenu retourné par Intermediate Steps : input de chaque outil, arguments utilisés, nombre de tokens consommés, une richesse d'information pour analyser le comportement de l'agent.
- Démonstration de manipulation des données de suivi pour extraire des métriques spécifiques comme le coût total en tokens, exploitables pour un tableau de bord de suivi de performance.

## Concepts cles
- introduction au suivi de performance via enregistrement dans Google Sheets
- présentation de l'option Return Intermediate Steps pour suivre les étapes de réflexion
- détail du contenu d'Intermediate Steps (inputs, arguments, tokens)
- démonstration d'extraction de métriques de coût en tokens pour suivi de performance

## Outils mentionnes
- n8n
- Google Sheets

## Tips techniques
- Ajouter systématiquement un enregistrement de suivi dans Google Sheets à la dernière étape d'un agent pour tracer sa performance dans le temps
- Activer l'option Return Intermediate Steps pour analyser en détail le raisonnement suivi par l'agent, utile pour le débogage et l'audit
