# 4.06 Le node AI Transform

## Resume
- Introduction au node AI Transform, capable de remplacer le Code node dans certains cas, avec démonstration sur un JSON de référence généré via IA pour illustrer son fonctionnement.
- Résolution en direct d'un problème de formatting JSON en ajoutant un objet englobant (« users »), démontrant le débogage itératif nécessaire pour un JSON structurellement correct.
- Démonstration de filtrage de données via prompt en langage naturel (salaire supérieur à un seuil ajustable) transformé automatiquement en code JavaScript exécutable par le node AI Transform.
- Synthèse de l'intérêt de l'AI Transform pour trier de grandes quantités de données sans savoir coder : l'IA génère la requête nécessaire, N8n la transforme automatiquement en code exécutable.

## Concepts cles
- introduction à l'AI Transform comme alternative au Code node
- résolution en direct d'un problème de formatting JSON par ajout d'objet englobant
- démonstration de filtrage via prompt naturel transformé en code JavaScript
- synthèse : AI Transform pour trier de grandes données sans compétence en code

## Outils mentionnes
- n8n

## Tips techniques
- Envelopper les données dans un objet nommé (ex : 'users') pour corriger un problème de formatting JSON invalide
- Utiliser l'AI Transform pour filtrer de grandes quantités de données sans savoir coder, en formulant simplement la requête en langage naturel
