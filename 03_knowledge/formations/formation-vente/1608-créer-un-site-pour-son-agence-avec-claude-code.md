# 16.08 Créer un site pour son agence avec Claude Code

## Resume
- Introduction à la création d'une landing page d'agence avec Claude Code, sommaire des étapes : no-code/IA, générateur de design system, configuration, génération, téléchargement des fichiers, introduction à l'IDE.
- Anecdote personnelle : refonte du site de l'agence en environ 5 heures à deux (avec Reynald), qui a structuré la partie complexe non abordée dans cette vidéo.
- Présentation du résultat final du site (vidéo, réservation d'appel, pages indexées, calculateur de ROI), avec précision qu'un travail conséquent a été investi.
- Précision personnelle : l'intervenant ne se considère pas comme développeur malgré une aisance relative avec le code acquise au fil des années.
- Affirmation que le site est en full code (pas de no-code ni de site builder), réalisé seul avec l'aide de Reynald et trois astuces (hacks) à venir.
- Présentation d'un outil personnel de génération de design system avec choix de spécialités (intégration IA, contenu) comme exemples de nommage.
- Transition vers l'IDE utilisé (Antigravity), avec définition simple d'un IDE comme un lecteur-éditeur de code avancé.
- Explication qu'Antigravity est l'IDE de Google, comme la plupart des IDE forkés depuis la base commune Visual Studio Code de Microsoft.
- Comparaison de deux forks de VS Code : Cursor et Antigravity (Google), ce dernier étant actuellement gratuit contrairement à l'équivalent Cursor.
- Début de la démonstration pratique dans Antigravity avec le fichier préparé en amont, avant le téléchargement des extensions nécessaires.
- Présentation de deux façons d'utiliser l'outil : directement dans le terminal de l'IDE (New Terminal) ou via l'extension dédiée, jugée plus simple à montrer.
- Explication de l'utilité de l'extension (visualiser le site dans un onglet), avec choix entre cloner un repo hébergé sur GitHub ou ouvrir un dossier existant.
- Recommandation de se concentrer sur trois éléments clés : la fenêtre Claude Code, l'ouverture d'un fichier via Open Folder, et les projets récents.
- Démonstration de correction d'un bug sur le header via Claude Code, avec première connexion nécessitant un compte Anthropic.
- Présentation du Plan Mode avec recommandation de faire un état des lieux via un prompt demandant à Claude d'utiliser le CLAUDE.md pour proposer un plan précis d'amélioration.
- Conseil de développer son œil de designer soi-même ou de demander à Claude de s'entraîner sur ce point, puis lancement d'un agent plan pour une stratégie d'amélioration complète.
- Présentation de deux modes d'application des modifications : tout accepter d'un coup (auto accept) ou approuver manuellement, avec recommandation d'auto accept pour débuter.
- Revue de la section héros du site généré avec ses chiffres modifiables (burnout créatif, incohérence, coût d'opportunité, machine de contenu pilotée par l'IA).
- Démonstration d'ajustements itératifs (animation, container repurposing, résultats prouvés, questions fréquentes, footer) via prompts successifs.
- Principe clé : itérer progressivement vers le résultat plutôt que d'utiliser des outils génériques type Lovable avec un prompt vague en espérant un résultat adapté.
- Conseil d'éduquer son œil de designer pour pouvoir ensuite décrire ses attentes comme si l'on parlait à un vrai designer, illustré par une petite animation générée rapidement.
- Démonstration d'ajout d'un mode clair via un prompt simple (Add Light Mode), avec insistance sur l'importance de ce processus itératif progressif.

## Tips techniques
- Se concentrer uniquement sur les éléments essentiels de l'interface IDE (fenêtre Claude Code, ouverture de fichier) au début, sans se soucier de la structure complète
- Utiliser le Plan Mode avec un prompt demandant explicitement à Claude de s'appuyer sur le CLAUDE.md du projet pour proposer un plan d'amélioration précis
- Développer son œil de designer en demandant à Claude de s'entraîner spécifiquement sur ce point, en complément du travail technique
- Utiliser le mode auto accept pour les modifications au début d'un projet, réserver l'approbation manuelle aux projets déjà bien avancés et maîtrisés
- Itérer de manière progressive sur un site généré par IA plutôt que d'espérer un résultat parfait avec un unique prompt générique
- Éduquer progressivement son œil de designer pour pouvoir décrire précisément ses attentes esthétiques à l'IA, comme on le ferait à un designer humain
