# neko-go-2026-10

Jeu mobile géolocalisé iOS + Android, « Pokémon Go pour les chats ». **Produit indépendant de Blue Impakt**, monétisé (freemium), build solo avec Claude Code, levée envisagée après la bêta.

## Objectifs du projet
- Hybride : vrais chats photographiés (jackpot) + chats virtuels (boucle quotidienne, zones sans chats)
- Rareté dégressive : plus un chat est capturé par des joueurs distincts, plus son niveau baisse
- Prouver la rétention (D1/D7/D30) sur une bêta concentrée avant de lever

## Livrables
- Spike ré-identification (go / plan B)
- Spec puis MVP phase 1 (noyau capture, une ville)

## Décisions techniques
- App : React Native + Expo (TypeScript). Flutter reste ouvert.
- Backend : Supabase (Postgres + PostGIS + pgvector). Dédup : filtre géo ~500 m puis similarité vectorielle.
- IA : détection YOLOX-nano / EfficientDet-Lite (pas YOLOv8, AGPL), découpe du fond avant stockage, embedding DINOv2-small (Apache-2.0, quantifié INT8), à confirmer sur photos réalistes.
- Monétisation : deux monnaies. Croquettes (gratuites, gagnées en jouant, jamais achetables, carburant de l'apparition des virtuels) et pâté (payant, cosmétiques exclusifs). Le pâté soigne aussi l'épuisement (soin plafonné, possible aussi en croquettes) ; PvP normalisé par ligues, donc pas de pay-to-win en compétition. Jamais d'achat de rareté d'un vrai chat.

## Blocages / risques
- Ré-id individuelle sous angles variés (tigrés, noirs) : plan B = rareté par type de chat
- Vie privée (chats de particuliers, fonds), modération UGC exigée par Apple, triche
- Pas de simulateur iOS sous Windows : tests iPhone via TestFlight
- Nom « Neko Go » : conflit de marque possible, à vérifier
- Une micro-entreprise ne peut pas lever : SAS/SASU dédiée le moment venu
